# Modelos de Arquitectura de Interlinking

## Hub-and-Spoke
Paginas pilar enlazan hacia articulos de apoyo y viceversa (bidireccional).
Ideal para blogs y sitios de contenido con jerarquia clara.

Reglas:
- La pilar enlaza HACIA todos sus articulos de apoyo
- Cada articulo de apoyo enlaza DE VUELTA a la pilar
- Los articulos de apoyo pueden enlazarse entre si si son muy relacionados

## Modelo SILO
Estructura piramidal por categorias tematicas aisladas.
NUNCA cruzar enlaces entre silos distintos.
Ideal para e-commerce y portales multitematicos.

## Interlinking en Cadena
Enlace lineal de MENOR volumen hacia MAYOR volumen.
NUNCA enlazar desde alto volumen hacia bajo volumen.
Ideal para webs pequenas (<30 URLs) o nicho.

## Modelo Vertizontal (Hibrido Recomendado)
Organizar verticalmente (SILO: por temas) + cadena dentro de cada silo.
Maximo control de autoridad sin romper relevancia tematica.

## Matriz de decision

| Situacion | Modelo recomendado |
|-----------|-------------------|
| <20 URLs, 1 tema | Cadena simple |
| 20-50 URLs, blog | Hub-and-Spoke |
| 20-50 URLs, e-commerce | SILO |
| >50 URLs, contenido mixto | Vertizontal |
| >50 URLs, e-commerce grande | SILO estricto |
