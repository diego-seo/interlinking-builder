# Anchor Text Avanzado

## Los 3 tipos de ancla obligatorios por par

### Ancla 1 - Exacta/parcial alta (5-10%)
Contiene la keyword principal. Max 1-2 palabras extra de contexto.
Ejemplo: "link building SEO", "estrategia de link building"

### Ancla 2 - Semantica/LSI (25-35%)
Sinonimo del mismo campo semantico. Misma intencion, diferente vocabulario.
Ejemplo: "construccion de enlaces externos", "adquisicion de backlinks"

### Ancla 3 - Long-tail descriptivo (55-70%)
Frase completa que describe el contenido y resuelve una intencion.
Ejemplo: "como conseguir enlaces externos de calidad para posicionar"

## Palabras PROHIBIDAS en anchor texts
- "haz clic aqui", "clic aqui", "leer mas", "ver mas"
- "mas informacion", "aqui", "este articulo", "este post"
- "enlace", "link", "visita", "sitio web", "ir a"

## Diversidad semantica
Las 3 anclas deben ser distintas:
- No mas del 40% de palabras en comun entre ellas
- Cada una con al menos 1 palabra unica
- Longitud: Ancla 1 (2-4 palabras), Ancla 2 (3-5), Ancla 3 (6-12)

## El vecindario del enlace
Google evalua las 50-100 palabras alrededor del anchor text.
Si el contexto aporta relevancia, el ancla puede ser mas breve.

Posicion optima:
- Intro (primeras 25%): mayor valor SEO
- Cuerpo (25-75%): zona ideal para long-tail
- Conclusion (75-100%): enlace de retencion
